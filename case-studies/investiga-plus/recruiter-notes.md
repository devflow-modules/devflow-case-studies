# Investiga+ Recruiter Notes

This document helps recruiters and technical interviewers evaluate the Investiga+ case study.

---

## What This Case Demonstrates

Investiga+ demonstrates fullstack SaaS delivery around a real business workflow: authenticated company lookup, structured results, cached searches, user history and dashboard-based analysis.

It combines:

- Secure authentication
- External API integration
- Backend modularization
- Database persistence
- Cache strategy
- User-scoped records
- Dashboard UX
- Automated testing
- Product-oriented thinking

---

## Strong Signals for Fullstack Roles

### Frontend

---

## Interview Discussion Topics

A technical interviewer could ask about:

- Why JWT was stored using HttpOnly Cookies
- How protected routes are validated
- How repeated CNPJ searches use cache
- How external API failures are handled
- How user search history is scoped
- How backend modules are separated
- How tests are structured around external integrations
- How this could evolve into a paid SaaS product

Evaluate this case as a fullstack SaaS and API integration project.

- Fullstack Engineer

## Summary

The strongest signal in Investiga+ is the ability to transform a repeated business process into a structured SaaS product with authentication, persistence, API integration, caching and product documentation.
