# Investiga+ Product Roadmap

This roadmap describes how Investiga+ can evolve from a CNPJ intelligence SaaS into a broader company analysis product.

---

## Product Vision

Build a SaaS platform that helps users validate, analyze and organize company data through CNPJ consultation, history, enrichment, dashboards and business workflows.

---

## MVP Foundation

The initial foundation includes:

- Secure authentication
- CNPJ search flow
- External company data lookup
- Cached company records
- User search history
- Dashboard interface
- Profile and account area
- Modular backend
- Automated test foundation

---

## Phase 1 — Core Stability

Goal: strengthen the current production foundation.

- Improve dashboard UX
- Add loading, error and empty states
- Improve validation feedback
- Expand backend tests
- Improve API error mapping
- Add structured logging
- Improve deployment documentation

---

## Phase 2 — Company Intelligence Views

Goal: move from raw CNPJ lookup to business intelligence.

- Company profile page
- Activity and category visualization
- Address and location details
- Company status indicators
- Search result comparison
- Recent searches dashboard

---

## Phase 3 — User Productivity

Goal: help users manage repeated analysis workflows.

- Favorite companies
- Notes per company
- Tags and segmentation
- Export search history
- CSV import for bulk consultation
- Batch processing queue
- Saved lists

---

## Phase 4 — Admin and SaaS Controls

Goal: prepare the product for broader SaaS operation.

- Admin dashboard
- User management
- Usage metrics
- Plan limits
- Search quota tracking
- Audit logs
- Billing foundation

---

## Phase 5 — Data Enrichment

Goal: increase product value with more intelligence features.

- Additional public data providers
- Risk indicators
- Lead qualification score
- Company enrichment modules
- API access for external systems
- CRM-oriented integration flows

---

## Monetization Opportunities

Potential paths:

- Freemium searches
- Monthly SaaS plan
- Search quota tiers
- Bulk analysis add-on
- API access plan
- White-label version for consultants and agencies
- Premium company intelligence reports

---

## Portfolio Signal

This roadmap demonstrates SaaS product thinking, user workflow design, monetization planning and technical scalability planning.
