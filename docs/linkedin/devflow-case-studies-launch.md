# LinkedIn Post — DevFlow Labs Case Studies

I have been organizing my GitHub portfolio around a clearer idea: showing not only code, but product engineering decisions.

Over the last few projects, I started documenting case studies from DevFlow Labs, my product engineering lab focused on SaaS, automation, AI-assisted workflows and reusable architecture.

The goal is simple: make it easier for recruiters, technical interviewers and potential clients to understand what each product solves, how it was designed and which engineering decisions were made.

Current priority cases:

- Investiga+ — CNPJ intelligence SaaS with authentication, API integration, cache strategy and user history
- DevFlow WhatsApp Platform — multi-tenant SaaS for WhatsApp operations, AI assistance, dashboards, billing and automation
- ApplyFlow — local-first job application workflow assistant focused on privacy, productivity and human-in-the-loop automation

Instead of treating documentation as an afterthought, I am using it as part of the product strategy.

Each case study is being structured with:

- Product context
- Architecture overview
- Security or privacy decisions
- Business value
- Roadmap
- Recruiter notes

This helps connect the technical implementation with the real business problem behind each project.

Stack and topics involved:

Next.js, React, TypeScript, Node.js, Express, Prisma, PostgreSQL, JWT, HttpOnly Cookies, Webhooks, WhatsApp Cloud API, OpenAI, Stripe, testing, CI/CD and SaaS architecture.

More than building isolated projects, my focus is to build products that can become real tools, SaaS products or white-label solutions.
